A minimal CLI for recording your commits. Early-stage project — the current release prints a banner and reserves the `g1t` command name.

## Install

```bash
npm install -g g1t
```

Or run from a clone:

```bash
git clone https://github.com/nirholas/g1t.git
cd g1t
node index.js
```

## Usage

```bash
g1t
```
